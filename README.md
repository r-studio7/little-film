# R's Little Film

VSCOみたいにプリセットで色味を変えられる、写真・動画（1本ずつ）用の編集アプリ。
`index.html` 1ファイルだけで動く（インストール不要・サーバー不要）。

## できること
- 写真 / 動画を開いて、13種類のプリセット（Analog, Soft Film, Golden, Cream, Vintage, Mono…）をワンタップで適用
- プリセットの「強さ」を0〜100で調整
- 調整：露出・コントラスト・彩度・色温度・色かぶり・ハイライト・シャドウ・フェード・ビネット・粒子
- 今の色味を「マイプリセット」として保存（ブラウザに保存される）
- フィルムタブ：光漏れ・ハレーション・ほこり/傷・フィルム粒子・レトロ枠・白フチ・日付スタンプ（おまかせ：使い捨てカメラ / シネマ / インスタント / ヴィンテージ / ネガ）
- 文字タブ：文字入れ（タイプ / 明朝 / Serif / Diary / Diary Serif / ゴシック / 手書き、大きさ・字間・濃さ・色＋カラーピッカー、ドラッグで移動）
- 角度タブ：まっすぐ（傾き補正）・縦横の遠近補正・90°回転・左右反転・枠の中で拡大＆ドラッグ（グリッド表示つき）
- インスタタブ：4:5 / 3:4 / 5:4 / 4:3 / 1:1 / 9:16 の背景にのせて書き出し、写真いっぱい／✉ タイトル入り（Postcards from / A love letter to のテンプレート）
- 文字タブの「✉ Postcards from」：POSTCARDS FROM ＋ 地名のタイトルをワンタップで（2行セットで動く）
- スポイト：写真から色を拾って、文字・背景・ポストカード文字の色に使える
- まとめて加工：写真を複数枚選ぶと、同じ加工を一気にかけてまとめて保存（角度・切り取り位置は1枚ずつ）
- ★タブ：お気に入り（色味・調整・フィルム・文字をまるごと保存して、ワンタップで適用）
- 画面を長押しでオリジナルと比較
- 保存：写真はJPEG、動画は色を焼き込んだmp4（Safari/Chrome）またはwebm。音声も入る

## 使い方
- PC：`index.html` をブラウザで開くだけ
- iPhone：https://r-studio7.github.io/little-film/ をSafariで開く →「ホーム画面に追加」でアプリっぽく使える

## 注意
- 動画の書き出しは「再生しながら録画」方式なので、動画の長さと同じだけ時間がかかる（短い動画向け）
- 書き出し中は画面を閉じない・他のアプリに切り替えない

## Claudeにまとめて加工してもらう
アプリの★タブで「お気に入りをファイルに書き出す」→ そのファイルと写真をClaudeに渡して、こう頼むだけ。

> この写真ぜんぶ、お気に入りの「パリの朝」で加工して

設定を直接言ってもOK：

> AN・強さ80・4:5・A love letter to Copenhagen でぜんぶ加工して

中身は `tools/littlefilm-batch.js`（使い方はファイルの先頭と CLAUDE.md に書いてあるよ）。
